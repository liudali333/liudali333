## 01 / ABOUT · 关于我

我关注 **AI、电商与自动化的结合**，探索从日常运营、数据处理到内容生产的工作流，也折腾 Docker、NAS 和自托管工具。

希望把零散的工具连接起来，让流程更顺畅，让时间留给判断与创造。
